# completion — shell tab-completion

print the shell tab-completion hook for bash/zsh/fish (needs argcomplete)

#### `pyramids completion`

print the shell tab-completion hook for bash/zsh/fish (needs argcomplete)

```text
pyramids completion [-h] {bash,zsh,fish}
```

| argument | | description |
|---|---|---|
| `shell` | required | the shell to emit a completion hook for (choices: `bash`, `zsh`, `fish`) |
