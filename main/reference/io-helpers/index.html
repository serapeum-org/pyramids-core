    In-memory rasters & array layout helpers#

    Top-level I/O and array utilities exported from pyramids.

    MemoryFile#

    An in-memory, /vsimem-backed raster file handle. Stage a raster by handing it encoded bytes (MemoryFile(ds.to_bytes()) or write()), open it as a Dataset, or read its bytes back; the buffer is unlinked on exit.

    pyramids._io.MemoryFile #

    An in-memory, VSI-backed raster file handle with deterministic cleanup.

    Wraps a GDAL /vsimem/ path so a raster can be built or staged in memory and handed to code that needs a filesystem-like path, then read back as bytes or opened as a :class:~pyramids.dataset.Dataset. The backing buffer is unlinked when the handle is closed (or when the object is garbage-collected, via :func:weakref.finalize).

    It mirrors the common in-memory raster-file-handle pattern, yielding a pyramids :class:~pyramids.dataset.Dataset. For a plain whole-buffer round-trip see :meth:Dataset.from_bytes / :meth:Dataset.to_bytes.

    Stage a raster by handing it encoded bytes -- MemoryFile(ds.to_bytes()) or :meth:write -- not by writing to :attr:name with Dataset.to_file (which does not target VSI paths). :attr:name is still a real /vsimem/ path for GDAL/VSI-aware consumers that accept one.

    An in-memory dataset opened from a MemoryFile should be consumed before the MemoryFile is closed (closing unlinks the shared buffer), and such datasets are not picklable.

    class MemoryFile:
    """An in-memory, VSI-backed raster file handle with deterministic cleanup.

    Wraps a GDAL ``/vsimem/`` path so a raster can be built or staged in memory
    and handed to code that needs a filesystem-like path, then read back as bytes
    or opened as a :class:`~pyramids.dataset.Dataset`. The backing buffer is
    unlinked when the handle is closed (or when the object is garbage-collected,
    via :func:`weakref.finalize`).

    It mirrors the common in-memory raster-file-handle pattern, yielding a pyramids
    :class:`~pyramids.dataset.Dataset`. For a plain whole-buffer round-trip see
    :meth:`Dataset.from_bytes` / :meth:`Dataset.to_bytes`.

    Stage a raster by handing it encoded bytes -- ``MemoryFile(ds.to_bytes())`` or
    :meth:`write` -- not by writing to :attr:`name` with ``Dataset.to_file`` (which
    does not target VSI paths). :attr:`name` is still a real ``/vsimem/`` path for
    GDAL/VSI-aware consumers that accept one.

    An in-memory dataset opened from a ``MemoryFile`` should be consumed before the
    ``MemoryFile`` is closed (closing unlinks the shared buffer), and such datasets
    are not picklable.

    Args:
        data: Optional raster bytes to stage immediately. When ``None`` (default)
            the handle just reserves a ``/vsimem/`` path to be written by other code.
        suffix: File-name suffix for the minted path (controls the format GDAL infers).

    Examples:
        - Stage bytes and open them as a Dataset:
            ```python
            >>> import numpy as np
            >>> from pyramids import MemoryFile
            >>> from pyramids.dataset import Dataset, GeoReference
            >>> ref = GeoReference(top_left_corner=(0, 0), cell_size=1.0, epsg=4326)
            >>> data = Dataset.from_array(np.ones((1, 3, 4), np.float32), geo_ref=ref).to_bytes()
            >>> with MemoryFile(data) as mf:
            ...     mf.open().shape
            (1, 3, 4)

            ```
    """

    def __init__(
        self,
        data: bytes | bytearray | memoryview | None = None,
        *,
        suffix: str = ".tif",
    ) -> None:
        if data is not None and not isinstance(data, (bytes, bytearray, memoryview)):
            raise TypeError(
                f"data must be bytes-like or None, got {type(data).__name__}."
            )
        self._path = new_vsimem_path(suffix)
        self._closed = False
        if data is not None:
            gdal.FileFromMemBuffer(self._path, bytes(data))
        self._finalizer = weakref.finalize(self, silent_unlink, self._path)

    @property
    def name(self) -> str:
        """The ``/vsimem/`` path (usable anywhere GDAL accepts a path)."""
        self._check_open()
        return self._path

    def open(self, *, read_only: bool = True) -> Dataset:
        """Open the in-memory file as a pyramids :class:`~pyramids.dataset.Dataset`."""
        self._check_open()
        # Local import breaks the pyramids.dataset <-> pyramids._io import cycle
        # (dataset.py imports _io at module load).
        from pyramids.dataset import Dataset

        return Dataset.read_file(self._path, read_only=read_only)

    def write(self, data: bytes | bytearray | memoryview) -> None:
        """Write (or overwrite) the in-memory file's contents with raster bytes.

        Args:
            data: Encoded raster bytes (e.g. from :meth:`Dataset.to_bytes`).
        """
        self._check_open()
        if not isinstance(data, (bytes, bytearray, memoryview)):
            raise TypeError(f"data must be bytes-like, got {type(data).__name__}.")
        gdal.FileFromMemBuffer(self._path, bytes(data))

    def read(self) -> bytes:
        """Return the current encoded bytes of the in-memory file.

        Raises:
            FileNotFoundError: Nothing has been written to the handle yet.
        """
        self._check_open()
        return read_vsi_bytes(self._path)

    def close(self) -> None:
        """Unlink the backing ``/vsimem/`` buffer (idempotent)."""
        if not self._closed:
            self._finalizer()
            self._closed = True

    def _check_open(self) -> None:
        """Raise if the handle has been closed."""
        if self._closed:
            raise ValueError("MemoryFile is closed.")

    def __enter__(self) -> MemoryFile:
        """Enter the context, returning the handle."""
        return self

    def __exit__(self, *exc: object) -> None:
        """Close the handle on context exit."""
        self.close()

    Array layout helpers#

    Convert between the band-first (bands, rows, cols) layout GDAL and pyramids use and the band-last (rows, cols, bands) layout image tooling expects. Both return a view (no copy).

    pyramids.base._utils.reshape_as_image(arr) #

    Reshape a band-first (bands, rows, cols) array to band-last (rows, cols, bands).

    pyramids and GDAL use the band-first layout (Dataset.read_array returns (bands, rows, cols)), while matplotlib / PIL and most image tooling expect the band-last (rows, cols, bands) layout. This is the inverse of :func:reshape_as_raster. Masked arrays are preserved.

    Returns a view with permuted strides (no copy); wrap it in np.ascontiguousarray(...) if you need C-contiguous memory.

    def reshape_as_image(arr: np.ndarray) -> np.ndarray:
    """Reshape a band-first ``(bands, rows, cols)`` array to band-last ``(rows, cols, bands)``.

    pyramids and GDAL use the band-first layout (``Dataset.read_array`` returns
    ``(bands, rows, cols)``), while matplotlib / PIL and most image tooling expect
    the band-last ``(rows, cols, bands)`` layout. This is the inverse of
    :func:`reshape_as_raster`. Masked arrays are preserved.

    Returns a view with permuted strides (no copy); wrap it in
    ``np.ascontiguousarray(...)`` if you need C-contiguous memory.

    Args:
        arr: A 3-D ``(bands, rows, cols)`` array.

    Returns:
        np.ndarray: The same data viewed as ``(rows, cols, bands)``.

    Raises:
        ValueError: If ``arr`` is not 3-D (a single-band ``(rows, cols)`` array must
            gain a band axis first, e.g. ``arr[None]``).

    Examples:
        - Move the band axis last for display:
            ```python
            >>> import numpy as np
            >>> from pyramids.base._utils import reshape_as_image
            >>> reshape_as_image(np.zeros((3, 4, 5))).shape
            (4, 5, 3)

            ```
    """
    if arr.ndim != 3:
        raise ValueError(
            f"expected a 3-D (bands, rows, cols) array, got ndim={arr.ndim}"
        )
    return np.moveaxis(arr, 0, -1)
